# EngiHelm changelog

## 1.0.0 — 2026-11-20

First public-facing EngiHelm-named *package edition* (no public redistribution license granted).
Preserves the 15-agent organization, local SQLite task tracking, guarded task closure,
unified completion checking, and Codex behavioral trial adapter.

- Detects previous Agile SDLC Orchestrator installations and requires migration acknowledgement before installation; neither existing Skills nor project data are deleted.
- Differentiates full-source development commands from scripts available in installed Skills.
- Aligns small/standard/high-risk review obligations with proportional review and truthful independence claims.
- Clarifies bundled Codex adapter versus the missing external Codex CLI and credentials.
- Records licensing status rather than selecting a public license on behalf of the owner.

**Compatibility:** Historical `sdlc-orchestrator` actor IDs remain unchanged. The
SQLite tracker and `docs/sdlc` project data are not migrated or reset by the installer.
**Validation limit:** No real Codex trials or external branch protections are included.
